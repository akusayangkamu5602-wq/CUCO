# CUCO Coin

CUCO is an experimental independent blockchain project.

## Project Parameters

- Name: CUCO Coin
- Symbol: CUCO
- Proposed maximum supply: 21,000,000 CUCO
- Consensus prototype: SHA-256 Proof of Work
- Proposed block interval: 10 minutes
- Proposed halving interval: 210,000 blocks

## Current Development Status

CUCO is currently an experimental prototype.

Implemented:
- Local blockchain storage
- SHA-256 block hashing
- Proof-of-Work mining prototype
- Wallet key generation and signature verification prototype
- Flask node API
- Peer registration
- Network handshake

Not yet production-ready:
- Secure decentralized peer-to-peer synchronization
- Complete transaction and balance consensus validation
- Public mining and reward distribution
- Network security audit

No public Mainnet launch is claimed at this stage.

## Development

The project is developed using Python and Termux.

## Warning

Do not use this prototype to store real funds.
Never share or publish wallet private keys.
